Flip Voca プライバシーポリシー

施行日：2026年10月27日

Jongcheol Yeom（以下「運営者」）は Flip Voca アプリ（以下「本アプリ」）を運営しています。本ポリシーでは、本アプリがどのような情報を、なぜ取り扱い、いつ削除するかを説明します。

1. 取り扱う個人情報

本アプリはログインしなくても使えます。その場合、学習記録はこの端末内にのみ保存され、運営者には送信されません。

  • ログインした場合：Google アカウントのメールアドレス、名前、プロフィール画像の URL（ログイン時に Google から提供される値）、アカウント識別子、ログイン日時
  • ログインした場合の学習記録：学習した単語カードごとの復習スケジュールと評価の記録、クリアしたステージ
  • 広告：広告識別子（Android の広告 ID、iOS ではトラッキングを許可した場合の IDFA）、端末・ネットワーク情報、IP アドレス。Google AdMob が広告の表示に使用します。
  • エラー情報：本アプリが異常終了したりエラーが発生したりしたときのエラー内容、端末のモデル、OS とアプリのバージョン。名前、メールアドレス、IP アドレスは送信しません。

2. 利用目的

  • 学習記録のバックアップと複数端末間の同期、アカウント管理
  • 無料でアプリを提供するための広告配信
  • エラー原因の分析とアプリの安定性向上

復習リマインダーは端末内で設定され、そのために個人情報をサーバーへ送信することはありません。

3. 保存期間と削除

  • アカウント情報と学習記録：アカウントを削除するまで保存し、削除時にサーバーと端末から遅滞なく削除します。
  • エラー情報：最長 90 日間保存した後、自動的に削除します。
  • 広告情報：Google のポリシーに従って Google が保存・削除します。

4. 第三者への提供

法令に基づく場合を除き、個人情報を第三者に提供しません。

5. 委託先と外国への移転

本アプリの運営のため、以下の事業者を利用しています。いずれも韓国外にあり、本アプリの利用中に暗号化された通信で情報が送信されます。

事業者国情報目的保存期間
Supabase Inc.シンガポール（東南アジアリージョン）アカウント情報、学習記録ログイン、記録の保存と同期アカウント削除まで

6. 利用者の権利

  • 開示・訂正・削除：本アプリの 設定 → アカウント → 退会する から、アカウントと学習記録をすぐに削除できます。本アプリを使えない場合はメールでご依頼ください（アカウント削除を参照）。
  • パーソナライズ広告の停止：iOS では初回起動時のトラッキング許可画面、または 設定 → プライバシーとセキュリティ → トラッキング で変更できます。Android では 設定 → プライバシー → 広告 で広告 ID を削除またはリセットできます。
  • EEA・英国の利用者：初回起動時に広告への同意を確認し、設定 → アカウント → 広告のプライバシー設定 でいつでも変更できます。

7. 安全管理

  • すべてのデータは暗号化された通信（HTTPS）で送信されます。
  • サーバー上の学習記録は、本人のアカウントだけが読み書きできます。
  • サーバーの管理権限は運営者だけが持っています。

8. 子どもの個人情報

本アプリは 14 歳未満の子どもを対象としておらず、14 歳未満の子どもの個人情報を故意に収集することはありません。保護者の同意なく収集したことが判明した場合は、遅滞なく削除します。
